BALAN STUDY — структура сайту
=============================
index.html            головна сторінка (весь текст — звичайний HTML, можна редагувати)
404.html              сторінка «не знайдено»
robots.txt, sitemap.xml, site.webmanifest, favicon.ico, favicon.svg
assets/videos/        review-1.mp4 … review-5.mp4      (відеовідгуки)
assets/images/        dmytro-balan.webp                (ваше фото)
                      review-1-poster.jpg … review-5-poster.jpg (обкладинки відео)
                      og-image.jpg                     (картинка для Telegram/Facebook/Google)
                      favicon-*.png, icon-*.png, apple-touch-icon.png

ПЕРЕД ПУБЛІКАЦІЄЮ: замініть YOUR-DOMAIN.com на вашу адресу (з https://, без слеша в кінці)
у трьох файлах: index.html, robots.txt, sitemap.xml  (Знайти й замінити в редакторі).
Потім: Google Search Console -> додати сайт -> надіслати sitemap.xml.
Сайт треба відкривати через хостинг; папка assets має лежати поруч з index.html.
